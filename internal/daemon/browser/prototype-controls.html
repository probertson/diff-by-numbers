Caching plan

An opening line.

The pricing service checks a rate table on every request. This plan caches the table in memory and refreshes it on a timer.

Why

Path Today Cached
p50 latency 42 ms 3 ms
p99 latency 310 ms 9 ms

A cached table can be up to refreshInterval old, which the finance team has agreed is fine for display prices.

Steps

  1. Load the table at start-up.
  2. Refresh it every five minutes.
  3. Serve every read from memory.
